# Ankush Pradhan — Creative Portfolio

A cinematic, interactive personal portfolio website for **Ankush Pradhan** (Photographer, Videographer, Video Editor & Colourist).

## Overview

- **Dynamic Scroll Canvas Engine**: Full-screen 238-frame background animation synchronized smoothly to scroll depth using high-precision exponential smoothing (LERP) and high-DPI canvas rendering.
- **Direct-on-Background Design**: Minimalist aesthetic with typography and cards floating directly on moving video frames with multi-layered high-contrast text shadows (zero frosted-glass blur layers or dark vignettes).
- **Curated Creative Disciplines**:
  - **Street Photography**: High-contrast street archives, Ganga Aarti portraits, and cultural festival coverage with an interactive full-resolution lightbox viewer.
  - **Product Photography & Commercials**: Commercial product showcases for perfumes, coins, audio tech, and jewelry brand films (Damayanti Jewellers & Malabar Gold).
  - **Wedding Films & Teasers**: Ceremony ritual archives, pre-wedding romantic series, and cinematic wedding teaser player.
  - **Video Editing & Colour Grading**: Multi-player showcase featuring bridal films, celebration reels, editing technique reels, and fitness commercials with landscape (-90° hardware rotation) and vertical (9:16) player support.
- **Direct Inquiries**: Integrated contact channels for Direct Phone, Email, and Instagram.

## Getting Started

### Prerequisites
- [Node.js](https://nodejs.org/) (v16 or higher)

### Run Locally
1. Clone the repository:
   ```bash
   git clone https://github.com/pradhanankush3-netizen/Ankush-Pradhan.git
   cd Ankush-Pradhan
   ```
2. Start the local server:
   ```bash
   node server.js
   ```
3. Open your browser and navigate to:
   ```
   http://localhost:3000/
   ```
